O que é uma VARIÁVEL?

⚽ Pense na camisa de um jogador...

É um espaço na memória para guardar um dado.

Exemplo no futebol: A camisa da Seleção é a variável. Hoje ela guarda o "Vini Jr", mas amanhã pode guardar outro jogador!

O que é uma estrutura condicional (IF / ELSE)?

⚽ Pense na consulta ao VAR...

Serve para o código tomar decisões com base em uma condição.

Exemplo:
SE (estava_adiantado) {
  anular_gol();
} SENÃO {
  validar_gol();
}

O que é um LOOP (Laço de repetição)?

⚽ Pense no treino de pênaltis...

É uma estrutura que repete uma ação várias vezes até uma condição ser atingida.

Exemplo: "Enquanto o jogador não cobrar 10 pênaltis, continue chutando."
